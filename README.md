# Profullstack Homebrew Tap

```sh
brew tap profullstack/tap
brew install c0mpute            # c0mpute node CLI (https://c0mpute.com)
brew install --cask nightcell7
```

## c0mpute

[c0mpute](https://c0mpute.com) is a decentralized compute network: run a node
on your own hardware and it serves inference, transcoding and storage jobs
from the network. `brew install profullstack/tap/c0mpute` installs the
`c0mpute` CLI from the signed GitHub release; start a worker with
`c0mpute worker start`. Earnings depend on network demand and vary. For the
full node stack (coinpay and infernet CLIs, payouts) use
`curl -fsSL https://c0mpute.com/install.sh | sh`.

`Formula/c0mpute.rb` is generated by `scripts/update-c0mpute.sh` from each
release's `.sha256` files; the `c0mpute formula` workflow refreshes it every
six hours.

## nightcell7

Casks here are generated from published GitHub releases by
[`nightcell7`](https://github.com/profullstack/nightcell7)'s
`tools/release/package-managers.mjs`, which reads each release's own
`SHA256SUMS.txt`. Do not hand-edit them — a manual change would be overwritten
on the next release, and could point at a checksum the release does not have.
